# Panduan demonstrasi yang dapat dipertanggungjawabkan

Semua perusahaan sintetis. Mode utama menyimpan catatan ke D1; gunakan staging untuk latihan. Sumber snapshot tidak memiliki seri bulanan, kontribusi resmi, persentil atau bukti lapangan.

1. Admin dapat membuat user; kedua peran aktif menggunakan alur analisis yang sama. Login testing mengikuti secret runtime, tidak disimpan dalam source.
2. Cari EMP-0348 di Peringkat. Detail memiliki tujuh bagian; peserta 8, pekerja 37, nilai tengah pembanding 35,5 dari 20 perusahaan, fallback sektor/skala. Rasio pendaftaran dari jumlah mentah dapat berbeda dengan indikator yang dibulatkan.
3. Penjelasan Skor menampilkan enam kategori dan tiga fokus, popup informasi kategori/metode. Jelaskan skor sumber 83,25 versus rekonstruksi indikatif 83,19; bukan SHAP, probabilitas atau bukti.
4. Di Ruang verifikasi, simpan hasil Sesuai dengan catatan dan tindakan. Sukses berarti ACK server. Kasus keluar dari antrean aktif dan masuk Kasus Selesai tanpa menurunkan risiko. User lain dapat memuat ulang dan membaca hasil yang sama. Koreksi hasil final wajib alasan.
5. EMP-0221 dapat disimpan Tidak Sesuai → Tindak lanjut Dalam proses → Tuntas dengan catatan. Pembukaan kembali wajib alasan. Riwayat tetap ada.
6. Untuk tambahan latihan dari lampiran, buka Tentang → Buka mode demonstrasi → baca konfirmasi → Aktifkan. Banner menunjukkan mode ini. Histori 24 bulan, posisi pembanding, peringatan dan alokasi adalah ilustrasi sintetis. Tombol skenario pada EMP-0348/0221 hanya mengisi draft, lalu pengguna meninjau dan menyimpan secara manual.
7. Catatan demo tersimpan per akun di browser dan tidak dikirim ke D1. Keluar demo atau refresh penuh kembali ke mode utama. Reset catatan demo tidak menghapus audit D1. Catatan localStorage lama tidak diimpor otomatis.

Jangan menyebut lampiran demo sebagai observasi atau hasil model. Jangan menampilkan dokumen bukti yang tidak ada. Sumber dan catatan pemeriksaan merupakan dua lapisan data terpisah.
